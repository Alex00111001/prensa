# Inicio de Enrique

Guía pública y script de preparación para Windows. Dos proyectos: Notas de prensa e Intervenciones y discursos.

## Uso
Descarga descargas/Instalador_Windows.zip, extrae ambos archivos y abre INSTALAR.cmd. Descarga y comprueba materiales públicos, crea la estructura en Documentos y solicita abrir ChatGPT de escritorio. No modifica políticas permanentes, no pide administrador y no instala ChatGPT si falta. Si una política corporativa lo impide, no la eludas.

La creación de los proyectos y la carga de instrucciones se realizan manualmente desde la guía. El script NO automatiza la interfaz de ChatGPT, no usa credenciales y no crea carpetas en Drive. El acceso a Google y la descarga de documentos privados se hacen después en el entorno de Enrique, con permiso y herramientas disponibles.

## Privacidad
Este repositorio NO incluye el documento Word original, el perfil privado, adjuntos, modelos de los correos, conversaciones, contraseñas ni tokens. Las plantillas publicadas son genéricas y no sustituyen el contexto privado. El progreso de la guía se guarda solo en el navegador o en un JSON que descarga el usuario.

## Actualizaciones
El instalador conserva archivos modificados; una versión pública distinta se guarda con sufijo .actualizacion-publica. Repetirlo no duplica el árbol. El manifiesto detecta descargas dañadas, no sustituye la revisión de la procedencia. Los estados de instalación local no acreditan proyectos ni carpetas de nube.

## Publicación
GitHub Pages debe estar habilitado. El workflow intenta configurar y publicar la web. Si GitHub exige autorización de administrador, elegir Settings → Pages → Source: GitHub Actions y volver a ejecutar el workflow. No hay backend ni claves en la web.
